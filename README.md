# Telecom Customer Churn Analysis

## О проекте

Исследовательский проект по анализу оттока клиентов телеком-компании. Цель — изучить характеристики клиентов и выявить признаки, связанные с уходом, используя SQL и Python.

## Задачи

- Проверить качество исходных данных.
- Подготовить типизированную таблицу для анализа в PostgreSQL.
- Сравнить уровень оттока между группами клиентов.
- Исследовать связь оттока с тарифными планами, обращениями в службу поддержки и использованием услуг.
- Проверить статистическую значимость отдельных различий.
- Сформулировать выводы и ограничения анализа.

## Инструменты

- **SQL / PostgreSQL** — очистка и проверка данных, группировки, агрегаты и анализ оттока.
- **Python** — исследовательский анализ данных (EDA).
- **pandas** — обработка и анализ данных.
- **Matplotlib** — визуализация.
- **SciPy** — статистические тесты.
- **Jupyter Notebook** — документирование анализа.

## Данные

В наборе данных 3333 записи о клиентах и 20 столбцов, включая характеристики тарифных планов, использование телефонной связи, обращения в поддержку и признак оттока.

## Основные результаты

- **Международный тарифный план:** доля оттока составляет 42,41% среди клиентов с планом и 11,50% среди клиентов без него. Критерий хи-квадрат выявил статистически значимую связь между этими признаками.
- **Голосовая почта:** доля оттока составляет 8,68% среди клиентов с голосовой почтой и 16,72% среди клиентов без неё.
- **Обращения в поддержку:** при четырёх обращениях доля оттока возрастает до 45,78% против 10,26% при трёх обращениях. Группы с большим количеством обращений малочисленны.
- **Дневная плата:** средняя плата у ушедших клиентов составляет 35,18 против 29,78 у оставшихся. Различие статистически значимо по результатам t-критерия Уэлча.

## Ограничения

Выявленные зависимости не доказывают причинно-следственную связь. Дневная плата связана с длительностью разговоров, а результаты для малочисленных групп требуют осторожной интерпретации.
